# Legal and License Policy

This repository tracks engineering evidence and does not provide legal advice.

## Required before reuse

- verify the license in the exact pinned revision;
- preserve required copyright, license, and NOTICE material;
- mark local modifications where required;
- inventory transitive dependencies;
- review non-code assets separately;
- remove or replace third-party trademarks and endorsement implications;
- review hosted API terms independently from source licenses;
- obtain specialist review for GPL, AGPL, custom, source-available, dual-license, patent-sensitive, payment, lending, identity, custody, or regulated functionality.

## Prohibited

- treating a public repository without a license as reusable;
- deleting attribution to disguise origin;
- claiming upstream sponsorship;
- combining dependencies without compatibility review;
- committing secrets, private source, production data, or proprietary upstream artifacts;
- deploying regulated financial functionality solely because example code is public.

## Distribution record

Every shipped product containing third-party code must generate a `THIRD_PARTY_NOTICES` artifact from the approved component inventory.
